Hemp Commerce SEO Engine v0.2.0

No products are created by this plugin.

v0.2 changes:
- Adds WooCommerce dependency warning in admin.
- Adds repair button: Seed WooCommerce Categories & Tags Only.
- Makes product categories hierarchical.
- Expands product categories and product tags for hemp, CBD, CBG, THCA, hemp-derived THC drinks, CBN sleep, wholesale, COA, and accessories.
- Adds seed result counts.
- Adds permalink flush button.

Install steps:
1. Ensure WooCommerce is installed and active.
2. Upload/replace this plugin ZIP.
3. Activate plugin.
4. Go to WP Admin > Hemp SEO Engine.
5. Click Seed WooCommerce Categories & Tags Only.
6. Then click Flush Permalinks.
